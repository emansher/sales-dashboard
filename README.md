# Sales Dashboard

A full-stack Sales Dashboard built with React, Vite, Recharts, Node.js, and Express.

The dashboard displays business performance data through interactive charts and summary statistics, with a category filter for exploring the data.

## Live Demo

- Frontend: https://sales-dashboard-ml11fkypy-emansher.vercel.app
- Backend: https://sales-dashboard-production-4c22.up.railway.app

## Features

- Total Sales, Orders, and Customers statistics
- Average Sales calculation
- Sales by Category bar chart
- Monthly Sales Trend line chart
- Sales Distribution pie chart
- Category filtering
- Responsive design for desktop, tablet, and mobile
- Frontend and backend deployed separately
- SEO metadata
- Accessible chart sections and controls
- Optimized production bundle

## Technology Stack

### Frontend

- React
- Vite
- Recharts
- CSS

### Backend

- Node.js
- Express
- CORS
